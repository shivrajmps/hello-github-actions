# AI Video Editing

All output from the yt-* skills is saved here.

| folder | from |
| --- | --- |
| scripts/ | /yt-script, /yt-seo, /yt-chapters |
| packaging/ | /yt-package (title + thumbnail pairings) |
| shorts/ | /yt-shorts |
| edits/ | /yt-edit (edit decision lists) |
| retention/ | /yt-retention, /yt-audit, /yt-viral, /yt-plan |

File naming: `<topic-slug>.md`, one file per video. Inputs you provide (transcripts, CSV exports) go next to the output that used them.

## What does not go here

No video, audio or image files. GitHub rejects files over 100 MB and git keeps every version, so one raw recording would break the repo. Keep footage, exports and thumbnail images on your drive or cloud storage, and put the filename or link in the markdown next to the edit list that refers to it. Text only here: scripts, transcripts, CSV exports, edit lists, titles.
